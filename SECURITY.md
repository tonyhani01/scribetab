# Security policy

## Supported version

The supported release line is `main`.

## Reporting a vulnerability

Please report suspected vulnerabilities through a private GitHub Security
Advisory for this repository. Do not open a public issue for a security
report; public reports can expose users before a fix is available.

The security scope includes the ScribeTab Chrome extension and native host.
API keys remain local to the browser profile and native-host configuration
unless the user explicitly sends them to a provider they configured.
